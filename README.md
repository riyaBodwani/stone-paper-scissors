# Stone Paper Scissors Game

A fun and interactive Stone Paper Scissors game developed using HTML, CSS, and JavaScript. The game allows users to play against a computer and keep track of their scores.

## Features
- Player vs Computer gameplay
- Random computer moves
- Win, Lose, and Draw detection
- Live score tracking
- Restart functionality
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!
